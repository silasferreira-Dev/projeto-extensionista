# Projeto Integrador Extensionista II

Este repositório contém a aplicação Full-Stack desenvolvida para a disciplina de **Projeto Integrador Extensionista II**. A aplicação integra uma API no Backend utilizando **Node.js** com **Express** e um Frontend dinâmico desenvolvido em **React** utilizando **Vite**.

---

## 🛠️ Tecnologias Utilizadas

### Backend
- **Node.js** - Ambiente de execução JavaScript
- **Express** - Framework web para criação de rotas e APIs
- **CORS** - Middleware para permitir requisições cross-origin entre o Frontend e o Backend

### Frontend
- **React** - Biblioteca JavaScript para construção da interface de usuário
- **Vite** - Ferramenta de build rápida para o ecossistema Frontend
- **CSS3 / HTML5** - Estilização e estruturação dos componentes
